Guide d'installation et d'utilisation · tout se fait sur ton PC, rien n'est envoyé ailleurs

Ton second cerveau, branché sur tes IA.

Axon est un dossier de notes reliées (dans ton Google Drive ou sur ton PC). Toi, tu le vois en 3D. Tes IA (Claude d'abord) le lisent, cherchent dedans, écrivent, modifient tes fichiers Excel et Word — sans jamais rien supprimer.

1. Installer Axon

  1. Télécharge l'installateur. Sur la page GitHub du projet, colonne de droite : Releases → la dernière version → Axon-Setup-1.0.0.exe.
  2. Double-clique sur Axon-Setup-1.0.0.exe. Si Windows affiche « Windows a protégé votre ordinateur » (l'app n'est pas encore signée par un certificat payant) : Informations complémentaires → Exécuter quand même.
  3. Suis l'assistant : choisis le dossier d'installation (ou laisse celui proposé) → Installer → Terminer. Rien à taper, pas de terminal, pas besoin d'installer Node.js : tout est dans l'installateur.
  4. Axon s'ouvre tout seul à la fin. L'icône Axon est sur le Bureau et dans le menu Démarrer. Compatible Windows 10 et 11 (64 bits).
Axon utilise automatiquement la carte graphique la plus puissante du PC pour l'affichage du cerveau 3D (sur un portable avec deux puces, la NVIDIA ou AMD plutôt que l'Intel). Pour vérifier : Ctrl+K → Matériel utilisé. L'IA locale (recherche par le sens) tourne sur le processeur, par paquets : mesuré plus rapide que la carte graphique pour ce petit modèle.
Ton cerveau (tes notes) n'est jamais dans le dossier de l'app. Tu peux réinstaller ou mettre à jour l'app sans rien perdre.

2. Le premier lancement

Axon te pose 3 questions :

  1. Ton prénom. Il signe ton journal et tes actions (utile quand vous êtes plusieurs sur le même cerveau).
  2. Où vit ton cerveau.
    Cloud : un dossier dans ton Google Drive (ex. G:\Mon Drive\Axon). Synchronisé partout, partageable avec un ami.
    Personnel : un dossier sur ce PC (ex. Documents\Axon).
    Le dossier choisi devient la racine : tout se crée dedans. Si tu choisis un dossier qui est déjà un cerveau Axon, tu le rejoins.
  3. Tes domaines de vie (École, Business, Finance, Trading… ajoute ou retire). Garde la case Brancher automatiquement Claude cochée.
Pour le mode Cloud, il faut Google Drive pour ordinateur (google.com/drive/download) : c'est lui qui fait apparaître G:\Mon Drive dans l'explorateur. Dans ses préférences, choisis Dupliquer les fichiers (« Mirror ») ou rends le dossier Axon disponible hors connexion : les IA lisent alors tout instantanément.

3. Brancher Claude

Claude Desktop (l'app Claude sur ton PC)

  1. Si la case était cochée au premier lancement, c'est déjà branché (Axon a écrit la configuration de Claude pour toi, avec une copie de sauvegarde). Sinon, dans Axon : Ctrl+K → Brancher Claude.
  2. Quitte Claude complètement — fermer la fenêtre ne suffit pas : en bas à droite, près de l'horloge, clic droit sur l'icône Claude (cherche dans la flèche ^ des icônes cachées) → Quitter.
  3. Rouvre Claude. Dans une nouvelle conversation, clique sur l'icône des outils (curseurs / « + ») : tu dois voir axon avec ses outils.
  4. Écris : Appelle brain_demarrer puis dis-moi ce que tu sais de moi. La première fois, Claude te demande l'autorisation d'utiliser l'outil : accepte (Toujours autoriser).

Claude Code (dans un terminal ou l'app)

Branché automatiquement s'il est installé. Pour vérifier : claude mcp list doit afficher axon … ✓ Connected. Les 7 skills sont dans ~/.claude/skills.

Sur un autre PC ou pour un ami

Il installe Axon avec le même Axon-Setup.exe et choisit le dossier du cerveau au premier lancement : Claude est branché automatiquement chez lui aussi.

5. Un cerveau à deux (toi + un ami, avec Google Drive)

  1. Toi : installe Axon, choisis Cloud et un dossier dans ton Drive, par exemple G:\Mon Drive\Axon Equipe.
  2. Partage ce dossier sur drive.google.com : clic droit → Partager → l'adresse Gmail de ton ami → Éditeur.
  3. Ton ami : sur drive.google.com → Partagés avec moi → clic droit sur le dossier → Organiser → Ajouter un raccourci dans « Mon Drive ». Le dossier apparaît alors dans son G:\Mon Drive.
  4. Ton ami installe Axon et, au premier lancement, choisit ce même dossier : Axon voit que c'est déjà un cerveau et propose de le rejoindre. Son Claude est branché sur le même cerveau.

Les subtilités, déjà gérées par Axon :

Chacun son journal01-Journal/2026/2026-11-11 Alex.md et … Sam.md : jamais le même fichier.
Chacun son log99-Systeme/Log/2026-11 Alex.md : les deux IA écrivent leur carnet de bord sans se marcher dessus.
Qui a écrit quoiChaque note dit son auteur. Une IA ne réécrit pas les mots d'un humain sans accord.
Rien ne se perdChaque modification garde l'ancienne version ; « supprimer » = archiver. Google Drive garde aussi 30 jours d'historique.
La seule règle : ne modifiez pas la même note au même moment. Sinon Google Drive crée une copie « (1) » au lieu de fusionner (rien n'est perdu, il faut juste recoller). Pour une équipe qui écrit beaucoup en même temps, on passe plus tard à Git (fusion ligne par ligne).

Conseil : garde deux cerveaux — ton cerveau perso (école, finance, trading : privé) et un cerveau d'équipe partagé (le business). Axon peut brancher les deux sur Claude : node cli\brain.mjs brancher "G:\Mon Drive\Axon Equipe" --nom axon-equipe.

6. La structure du cerveau

Une seule règle : tous les domaines ont le même moule. L'IA sait donc toujours où ranger, et le cerveau peut grandir sans fin.

Axon/ ├─ 00-COMMENCER-ICI.md ← l'accueil : qui tu es, tes domaines (la 1re page que lit une IA) ├─ 00-Inbox/ ← tout ce qui arrive en vrac · _archive/ = la « corbeille » récupérable ├─ 01-Journal/2026/ ← une note par jour et par personne ├─ 05-Noyau/ ← Objectifs, mémoire des IA, registres (décisions, leçons, blocages) ├─ 10-Ecole/ ← un DOMAINE : │ ├─ Ecole.md le hub (objectifs, projets en cours, savoir clé, décisions) │ ├─ Projets/Examen BAC/ un projet = un dossier = un neurone, avec ses fichiers à côté │ ├─ Savoir/ Decisions/ Ressources/ Archives/ ├─ 20-Business/ 30-Finance/ 40-Trading/ … (même moule, jusqu'à 69) ├─ 70-Savoir/ ← concepts utiles à plusieurs domaines ├─ 75-Personnes/ ← une note par personne ├─ 80-Sources/ ← vidéos, articles, livres, cours (avec le lien) ├─ 90-Fichiers/ ← fichiers importés sans place précise ├─ 95-Flux/ ← données automatiques (marchés, météo…) └─ 99-Systeme/ ← index, Log/, Membres, régions du cerveau 3D, modèles

Comment les notes se relient

LienCommentÀ quoi ça sert
Vers le hautparent: "[[Business]]" en tête de noteChaque note sait où elle habite. On ne se perd jamais.
De côtéAu moins 2 [[liens]] dans le texteLes idées se croisent entre domaines (un cours d'économie ↔ ta stratégie de trading). C'est ce qui rend le cerveau intelligent.
Les hubsChaque domaine et chaque projet a sa note-carteL'IA lit le hub avant d'ouvrir 50 notes : rapide et peu coûteux.
AutomatiqueUn _index.md par dossier, la recherche par le sensL'IA trouve aussi ce qui n'est pas relié à la main.

Le log et l'index, c'est quoi ?

Le log (99-Systeme/Log/) est le carnet de bord : une ligne par action — date, qui, ce qui a changé. On n'efface jamais. Une IA qui arrive lit les dernières lignes pour savoir ce qui s'est passé.
L'index (99-Systeme/index.md) est le sommaire des notes importantes. Et chaque dossier a un _index.md automatique : une ligne de résumé par note.

7. Excel, Word, PowerPoint dans les neurones

Range tes fichiers dans le neurone qu'ils concernent : 30-Finance/Projets/Budget 2027/Budget 2027.xlsx à côté de Budget 2027.md. Ensuite, demande simplement à Claude :

« Lis mon budget 2027 »Claude lit le tableau (feuilles, cellules, formules).
« Mets les courses à 350 et ajoute la ligne Février »Modifié sur place, mise en forme et formules gardées.
« Remplace le prof par M. Martin dans le plan de cours »Word et PowerPoint : texte remplacé, gras et styles gardés.
« Fais-moi un graphique à partir de ce fichier »Claude sort une copie, travaille avec ses propres outils, puis la remet dans le neurone.
À chaque modification, l'ancienne version est gardée. « Reviens à la version d'avant » suffit.

9. Désinstaller ou réinstaller

Comme n'importe quelle app : Paramètres Windows → Applications → Applications installées → Axon → Désinstaller. Le désinstallateur retire aussi Axon de Claude Desktop et Claude Code. Ton cerveau (tes notes) n'est jamais supprimé. Pour mettre à jour : lance simplement le nouvel Axon-Setup.exe par-dessus ; tes réglages et ton cerveau restent.
