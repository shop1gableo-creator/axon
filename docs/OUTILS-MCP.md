# Outils MCP d'Axon (30 outils, 8 prompts)

> Fichier généré par `node tools/doc-outils.mjs` à partir du serveur : ne pas modifier à la main.

Ordre conseillé pour une IA : `brain_demarrer` → `brain_skill` (le mode d'emploi de la tâche) → `brain_contexte` → agir → `brain_journal` / `brain_cloture`.

| Outil | Ce qu'il fait | Paramètres (? = optionnel) |
|---|---|---|
| `brain_carte` | Carte du Brain : règles (CLAUDE.md) + carte automatique des dossiers. À lire en premier. | — |
| `brain_chercher` | Recherche hybride (mots + sens) dans tout le Brain. Renvoie titres, chemins et résumés. | `requete`, `nombre`? |
| `brain_contexte` | Paquet de contexte compact pour répondre à une question : notes les plus pertinentes en entier + voisines en résumé. | `question`, `mots_max`? |
| `brain_lire` | Lit une note (par nom ou chemin). | `note` |
| `brain_liens` | Liens sortants, rétroliens et notes proches par le sens d'une note. | `note` |
| `brain_ecrire` | Crée ou remplace une note Markdown (chemin relatif .md). Ne supprime jamais rien. Respecte les règles de CLAUDE.md (frontmatter, liens, mots humains intacts). | `chemin`, `contenu`, `raison`? |
| `brain_ajouter` | Ajoute du texte à la fin d'une note existante (sans toucher au reste). | `note`, `texte` |
| `brain_importer` | Importe n'importe quel fichier du PC (vidéo, image, son, PDF, texte, Markdown…) dans le Brain : copie rangée par mois + fiche. Une vidéo ou un son est transcrit automatiquement (Whisper local), une image reçoit le texte qu'elle contient (OCR), un PDF / Word / PowerPoint / Excel est converti en Markdown (texte cherchable). | `fichier`, `description`? |
| `brain_demarrer` | À APPELER EN PREMIER par toute IA qui découvre ce cerveau : qui sont les humains de ce cerveau, la carte des régions, ce que les IA savent déjà d'eux, les dernières actions et le protocole de travail. Une seule lecture suffit pour commencer. | — |
| `brain_apprendre` | Ajoute à la mémoire des IA (« Ce que les IA savent de nous ») un fait DURABLE appris sur les humains de ce cerveau ou leur entreprise. Une ligne, datée et sourcée automatiquement. Sections : qui, preferences, business, outils, projets, questions. | `fait`, `section`, `source`?, `ia`? |
| `brain_cloture` | RITUEL DE FIN DE SESSION (2 minutes, à faire à la fin de tout travail qui compte) : ce qui a été fait, les décisions prises (avec le pourquoi), les leçons apprises, les blocages et leur solution. Range tout dans les registres du Noyau et dans la note du jour. | `resume` (Ce qui a été fait pendant la session, en une ou deux phrases), `decisions`?, `lecons`?, `blocages`?, `notes`? (Notes touchées pendant la session), `ia`? |
| `brain_skill` | Les SKILLS d'Axon = comment bien travailler avec ce cerveau. Sans nom : liste. Avec un nom : le mode d'emploi complet à suivre. Disponibles : axon-architecte, axon-capturer, axon-compiler, axon-developpeur, axon-entretien, axon-fichiers, axon-repondre. Lis le bon skill AVANT une tâche de ce type (capturer, répondre, compiler, entretenir, restructurer, coder). | `nom`? |
| `brain_creer_neurone` | Crée un NEURONE (une note) dans une région du cerveau, avec texte, médias importés et liens vers d'autres neurones. L'app Brain le montre naître en direct. Régions : Noyau, E-com, Finance, Savoir, Projets, Système, Banques. Pour en créer plusieurs reliés entre eux, appelle cet outil plusieurs fois (le premier d'abord). | `titre`, `region`, `texte`?, `liens`? (Titres des neurones à relier), `medias`? (Chemins de fichiers du PC à importer et intégrer), `tags`?, `ia`? |
| `brain_dossier` | Liste un dossier du cerveau : sous-dossiers, notes (avec leur résumé) et fichiers (type, taille). Sans chemin : la racine. Pour naviguer comme dans l'explorateur, mais en sachant ce que contient chaque note. | `chemin`? |
| `brain_modifier` | Modifie un document texte du cerveau (note .md, code .js/.c/.cs/.py/.mq5, .csv, .json, .txt…) en remplaçant un passage EXACT par un autre. La version précédente est sauvegardée (restaurable avec brain_versions). Pour une note écrite par Gabriel ou Léo, il faut confirme_humain: true (seulement si l'utilisateur l'a demandé). | `fichier`, `chercher`, `remplacer`, `tout`?, `confirme_humain`?, `raison`? |
| `brain_creer_fichier` | Crée (ou remplace, avec ecraser: true) N'IMPORTE QUEL fichier texte dans le cerveau : note, code (.js, .c, .cs, .py, .mq5…), CSV, JSON, HTML, script. Le dossier est créé si besoin. Si le fichier existait, l'ancienne version est sauvegardée. Pour importer un fichier binaire du PC (image, vidéo, PDF), utilise brain_importer. | `chemin`, `contenu`, `ecraser`?, `raison`? |
| `brain_deplacer` | Déplace ou renomme une note, un fichier ou un dossier du cerveau. Les [[liens]] qui pointaient vers une note renommée sont mis à jour partout. Ne remplace jamais un fichier existant. | `de`, `vers`, `raison`? |
| `brain_archiver` | « Supprimer » sans perdre : déplace une note, un fichier ou un dossier dans 00-Inbox/_archive/ (règle du cerveau : on ne supprime jamais). Récupérable à tout moment avec brain_deplacer. | `chemin`, `raison`? |
| `brain_versions` | Liste les anciennes versions d'un fichier (sauvegardées à chaque modification par l'IA) et peut en restaurer une (restaurer: nom de la version). La version actuelle est elle-même sauvegardée avant restauration. | `fichier`, `restaurer`? |
| `brain_office` | Lit ou MODIFIE SUR PLACE un fichier Office du cerveau sans casser sa mise en forme. Excel (.xlsx) : action « lire » (tableau, option feuille / plage ex. A1:F40) ou « ecrire » (cellules {"B3": 120, "C3": "=B3*2"}, lignes à ajouter à la fin, nouvelle_feuille). Word (.docx) et PowerPoint (.pptx) : « lire » (texte par paragraphe / diapo) ou « modifier » (remplacements [{chercher, remplacer}] au texte EXACT lu avant, ajouter = paragraphes à la fin ou dans la diapo). L'ancienne version est toujours gardée (brain_versions pour revenir). Lis TOUJOURS avant de modifier. | `fichier` (Chemin ou nom du fichier (.xlsx, .docx, .pptx)), `action`, `feuille`?, `plage`?, `cellules`?, `lignes`?, `nouvelle_feuille`?, `remplacements`?, `ajouter`?, `diapo`? |
| `brain_sortir` | Copie un fichier du cerveau (n'importe quel format : Excel, Word, PowerPoint, image, PDF, code…) dans un dossier de travail sur ce PC, pour le modifier avec un vrai outil (Python, Excel, script…). Renvoie le chemin de la copie. Quand c'est fini : brain_remettre avec ce chemin. | `fichier` |
| `brain_remettre` | Remet dans le cerveau un fichier du PC : la copie modifiée d'un brain_sortir (elle reprend sa place, l'ancienne version est gardée), ou un NOUVEAU fichier (Excel, Word, image…) à ranger dans un neurone (destination = dossier ou chemin dans le cerveau, ex. « 30-Finance/Projets/Budget 2027 »). Option note : intègre le fichier dans cette note avec ![[…]]. | `chemin_local`, `destination`?, `note`? |
| `brain_creer_domaine` | Ajoute un DOMAINE de vie au cerveau (ex. Santé, Sport, Musique, Immobilier) avec le moule complet : dossier numéroté, hub <Domaine>.md, Projets/, Savoir/, Decisions/, Ressources/, Archives/, une région dans le cerveau 3D et un lien depuis l'accueil. Vérifie d'abord avec brain_dossier qu'il n'existe pas déjà. | `nom`, `description`? |
| `brain_fichier` | Donne N'IMPORTE QUEL fichier du cerveau en QUALITÉ D'ORIGINE : image, vidéo, son, PDF, Word, Excel, PowerPoint, code (.js .c .cs .py .net…), texte. Renvoie le chemin exact du fichier d'origine, sa taille, son empreinte SHA-256 ; pour une image, l'image elle-même ; pour un document ou du code, son texte ; pour une vidéo, sa durée, sa miniature et sa transcription si elle existe. Option copier_vers : copie le fichier d'origine, octet pour octet, dans un dossier de travail. Trouver un fichier : brain_banque ou brain_chercher. | `fichier` (Chemin dans le cerveau (ex. 30-Finance/Projets/Budget 2027/Budget 2027.xlsx) ou nom du fichier), `copier_vers`? (Dossier du PC où copier l'original (créé si besoin)), `apercu`? (Joindre l'image (par défaut oui pour les images de moins de 5 Mo)) |
| `brain_parcourir` | Suit les LIENS à partir d'un neurone, sur 1 à 3 niveaux, et rend une carte compacte (titre + résumé d'une ligne par neurone, sens du lien). Idéal pour comprendre une zone du cerveau sans lire chaque note : beaucoup moins de tokens. Ensuite, brain_lire seulement les notes utiles. | `note`, `profondeur`?, `max`?, `sans_systeme`? |
| `brain_banque` | Trouve des médias dans les banques (images, détourages, clips vidéo, photos : tout dossier Banques/ qui a un _manifest.json). Filtres combinables : texte libre, banque, catégorie ou thème, marque, couleur, format (vertical / horizontal), hd. Renvoie le chemin de chaque fichier dans le Brain et sa description. Lire d'abord « Banques de contenu ». | `texte`?, `banque`?, `categorie`?, `marque`?, `couleur`?, `format`?, `hd`?, `nombre`? |
| `brain_recent` | Notes modifiées récemment. | `nombre`? |
| `brain_journal` | Ajoute une ligne au log du Brain ET à la section « Agents IA » de la note du jour (qui a fait quoi). | `texte`, `notes`? |
| `brain_maj` | Met à jour TOUT le cerveau : flux API (marchés, crypto, devises, veilles, météo), chiffres de la note du jour, index automatiques et rapport de santé. À utiliser quand on dit « mets tout à jour ». | — |
| `brain_sante` | Met à jour les index automatiques et le rapport de santé (liens cassés, orphelins, doublons…). | — |

## Prompts (menu « + » de Claude Desktop)
- **demarrer** : Prépare l'IA : lit le point d'entrée et la mémoire, puis attend la tâche.
- **axon-architecte** : Concevoir et faire grandir la STRUCTURE d'un cerveau Axon (domaines, projets, liaisons, régions 3D, banques de médias, cerveau partagé) pour qu'il reste rapide et clair à 100, 10 000 ou 100 000 notes. À utiliser pour ajouter un domaine de vie, un projet, réorganiser, décider comment relier des choses, ou quand le cerveau devient lent ou confus.
- **axon-capturer** : Faire entrer quelque chose dans le cerveau Axon (lien, article, vidéo, PDF, image, Excel, Word, code, conversation, idée en vrac) et le ranger au bon endroit, relié. À utiliser dès qu'on dit « garde ça », « mets dans le cerveau », « ajoute », « range », ou qu'on donne un fichier ou une URL à retenir.
- **axon-compiler** : Transformer le brut du cerveau Axon (Inbox, sources, fichiers marqués a-compiler) en notes de savoir atomiques, résumées et reliées (méthode LLM Wiki de Karpathy), et tenir les hubs à jour. À utiliser pour « range le cerveau », « trie l'inbox », « mets à jour », ou après plusieurs captures.
- **axon-developpeur** : Comprendre, réparer et étendre le CODE de l'application Axon (Electron, cerveau 3D, moteur, serveur MCP, CLI, connecteurs). À utiliser pour ajouter un outil MCP, un connecteur de données, un widget, une forme du cerveau 3D, corriger un bug, optimiser, ou expliquer comment Axon fonctionne.
- **axon-entretien** : Garder le cerveau Axon en bonne santé et le consolider (contrôle de santé + « rêve » de fin de journée) — liens cassés, orphelins, doublons, notes sans résumé ni parent, inbox à trier, hubs à jour, leçons de la semaine. À utiliser pour « vérifie », « nettoie », « répare », « fais le point », chaque soir ou chaque semaine.
- **axon-fichiers** : Travailler sur les FICHIERS rangés dans les neurones du cerveau Axon — lire et modifier un Excel, un Word, un PowerPoint, un PDF, une image, du code ; en créer de nouveaux ; les sortir pour les retravailler puis les remettre ; revenir à une ancienne version. À utiliser dès qu'une demande touche un fichier (« mets à jour mon budget », « corrige le plan de cours », « fais-moi un tableau », « ajoute une diapo »).
- **axon-repondre** : Répondre à une question en s'appuyant sur le cerveau Axon, avec les sources, puis garder la réponse si elle compte. À utiliser pour toute question sur la vie, l'école, le business, la finance, le trading, les projets, les décisions passées, « qu'est-ce qu'on sait sur… », « où est… », et quand on dit « garde cette réponse ».
